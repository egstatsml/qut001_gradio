# LLM Demo Generated-Text Readout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In `apps/llm_demo.py`, replace the toggleable "Generation history" table section with an always-visible readout that shows the student's initial prompt (italicised, muted) followed by the text they generated by choosing the AI's predictions.

**Architecture:** All changes are confined to the single file `apps/llm_demo.py`. Three pure HTML-builder functions render the new readout; the existing callback state (`original_prompt_state`, `context_state`) already contains everything needed, so the readout slots into the existing `common_outputs` chain in place of the step-log table. The step-log state, the Dataframe, its builders, its toggle buttons, and the redundant per-choice re-inference are deleted.

**Tech Stack:** Python 3.12, Gradio 6, repo virtualenv at `.venv` (run every command with `.venv/bin/python`). No new dependencies. The model must NOT be loaded during verification — `load_model()` is lazy (only called inside `get_predictions`), and module import builds the whole Blocks UI without touching the model.

**Spec:** Approved short design from the 2026-09-04 brainstorming session (bounded change, no spec file). The approved design is reproduced verbatim in "Design Summary" below — the plan argues from it.

## Design Summary (approved)

Replace the toggleable history section with an always-visible "generated text" card, in the same spot (underneath the prediction/choice activity):

1. Remove the "View generation history" button and the hidden history panel (Choice/Probability/etc. table), along with its now-dead plumbing (`step_log_state`, `build_step_log_df`, `show_history`/`hide_history`, `step_log_table`).
2. Add a panel card with a small heading consistent with the app's style, and a body that renders:
   - the **initial prompt in italics, muted grey** (de-emphasised), then
   - the **generated text** — everything the student added after the prompt (`context_state` minus `original_prompt_state`) — in normal ink, with `white-space: pre-wrap` so model-produced newlines display naturally.
3. Live-updating: recomputed on every choice and on reset, replacing the `step_log_table` slot in the existing `common_outputs` callback chain — no new state needed.
4. Empty state: a dashed placeholder message before any text has been generated, matching the existing empty-state pattern.

**Implementation note (deviation from the sketch, for correctness):** the generated portion is NOT whitespace-stripped. Qwen tokens almost always carry a leading space (e.g. `" it"`), and the prompt typically has no trailing space; stripping would join words incorrectly (`"…help usit"`). `pre-wrap` on the container preserves the natural space with no visible artifact. The `generated-delta` span may be empty (started but no choices yet) — the italic prompt is still shown; the placeholder appears only when `context` is falsy (never started, or reset).

## Global Constraints

- Only `apps/llm_demo.py` changes. Do not touch any other file.
- The new section is **always visible** — no toggle button, no `visible=False` panel.
- **Copy is fixed:** heading `Your generated text`; subtitle `Your starting prompt, then the text you built from the AI's predictions.`
- **Invariant (relied on by `build_generated_text_html`):** `context_state` always starts with `original_prompt_state` as a character-exact prefix. This holds by construction: `on_start` sets both to the raw prompt; choices only ever append `context + token_text`; `on_reset` wipes both to `""`; `on_stop`/`show_advanced_help` never mutate them; while paused the token bubbles are hidden so no selection can fire.
- The 18px readability floor (the app's design rule) applies to the new readout: the muted prompt is de-emphasised via colour + italics only, never via smaller font size.
- Remove the redundant per-choice satellite inference in `on_choose` (the `get_predictions(context, …)` re-run used only to build the deleted step-log probability). This saves one model inference per choice.
- Run everything with `.venv/bin/python` from repo root.
- Verification never loads the model: use the stubbed-`get_predictions` technique shown in Task 2.

```python
def empty_generated_text_html():
    return (
        "<div class='generated-text-empty'>"
        "Your generated text will appear here as you choose what comes next."
        "</div>"
    )


def generated_text_heading():
    return """
    <div class="section-heading">
      <div><h2>Your generated text</h2><p>Your starting prompt, then the text you built from the AI's predictions.</p></div>
    </div>
    """


def build_generated_text_html(original_prompt, context):
    """Render the student's starting prompt (italicised, muted) followed by
    the text they built by choosing the AI's predictions. Whitespace is
    preserved via CSS pre-wrap so model-produced spaces/newlines display
    naturally; the generated part is intentionally NOT stripped (the first
    generated token usually carries the separating space)."""
    if not original_prompt or not context:
        return empty_generated_text_html()

    prompt_html = html.escape(original_prompt)
    generated = context[len(original_prompt):]  # safe: prefix invariant, see Global Constraints
    generated_html = html.escape(generated)

    return (
        f"<div class='generated-text-body'>"
        f"<span class='generated-prompt'>{prompt_html}</span>"
        f"<span class='generated-delta'>{generated_html}</span>"
        f"</div>"
    )
```

def on_choose(selection, original_prompt, context, choice_number, top_k, tokens):
    top_k = int(top_k)
    choice_number = int(choice_number)

    try:
        index = int(str(selection).split(":", 1)[0])
    except (TypeError, ValueError):
        index = -1

    if not original_prompt or not tokens or index < 0 or index >= len(tokens):
        return (
            gr.update(),
            gr.update(),
            "",
            gr.update(),
            gr.update(), gr.update(), gr.update(),
            gr.update(), gr.update(),
            original_prompt, context, choice_number, top_k, tokens,
            gr.update(value=build_generated_text_html(original_prompt, context)),
        )

    token_text = tokens[index]
    new_context = context + token_text

    if choice_number >= MAX_GENERATION_CHOICES:
        return (
            gr.update(),
            empty_token_choices_html("Maximum of 100 choices reached."),
            "<div class='done-message'>Maximum of 100 choices reached.</div>",
            gr.update(value=f"Done after {MAX_GENERATION_CHOICES} choices", visible=True),
            gr.update(interactive=True), gr.update(interactive=False), gr.update(interactive=True),
            gr.update(value=new_context, interactive=True), gr.update(interactive=True),
            original_prompt, new_context, choice_number, top_k, [],
            gr.update(value=build_generated_text_html(original_prompt, new_context)),
        )

    new_tokens, new_probs = get_predictions(new_context, top_k)
    fig = build_probability_chart(new_tokens, new_probs)
    next_choice = choice_number + 1

    return (
        fig,
        token_choices_html(new_tokens, new_probs, interactive=True),
        "",
